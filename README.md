# PAVA Studio 업데이트

PAVA Studio의 공식 업데이트 페이지입니다.

> [!IMPORTANT]
> PAVA Studio를 처음 사용하려면 HIROBOT이 발급한 USB가 필요합니다. 이 페이지의 파일만으로는 실행되지 않습니다.

인터넷에 연결되어 있으면 PAVA Studio가 새 버전을 자동으로 받습니다. **업데이트 후 재시작**을 선택하면 업데이트하며, 사용권과 작품은 그대로 유지됩니다. PAVA가 다시 시작될 때까지 USB를 빼지 마세요.

## 파일 안내

`PAVA-Studio.exe`와 `pava-release.json`은 앱 내 업데이트용입니다. GitHub의 **Source code (zip)** 및 **Source code (tar.gz)** 파일은 이 저장소의 문서 압축 파일이며, 앱이 아닙니다. 오픈 소스 구성요소의 소스는 [pava-studio-third-party-source](https://github.com/hirobot-kr/pava-studio-third-party-source/releases)에 있습니다.

## English

Official update page for PAVA Studio.

> [!IMPORTANT]
> To start using PAVA Studio, you need a USB issued by HIROBOT. The files on this page do not run by themselves.

With an internet connection, PAVA Studio downloads new versions automatically. Choose **Update and restart** to install one; your license and projects stay with you. Keep your USB connected until PAVA restarts.

- [Product information](https://www.hirobot.com/pava/) · [Manual](https://www.hirobot.com/pava/#manual) · [FAQ](https://www.hirobot.com/pava/#faq)
- [Latest release notes](https://github.com/hirobot-kr/pava-studio-downloads/releases/latest) · [Release history](https://github.com/hirobot-kr/pava-studio-downloads/releases)
- Support: [contact@hirobot.com](mailto:contact@hirobot.com)

`PAVA-Studio.exe` and `pava-release.json` are for in-app updates. GitHub's **Source code (zip)** and **Source code (tar.gz)** files contain this repository's documents, not the app. Open-source component sources are in [pava-studio-third-party-source](https://github.com/hirobot-kr/pava-studio-third-party-source/releases).
